# 40m-Pebble-HF-Radio
Specific details associated with the MWRS 40m Pebble Radio

This repository contains the resources which augment the original Pebble HF Radio website to support the Manly Warringah Radio Society (MWRS) 40m Pebble HF build.
Most documentation to support the Pebble HF Project can be found here: https://pebblehf.com/docs.html .

The main document in this repository is the Construction and Operations Manual for the 40m Pebble Radio built by the MWRS Builders Group.
